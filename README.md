# 评价整理台

本地浏览器CSV规则整理工具：保留原文、去重、关键词分类、人工更改和导出。规则不等于因果归因，本工具没有调用AI模型。演示使用明确标记的合成数据。

无需安装依赖。静态HTTP服务打开index.html；测试运行 `node --test test/core.test.mjs`。CI通过后由GitHub Pages展示；不提供支付、账户或平台数据抓取。

仅UTF-8 CSV，2MB、5000条以内。数据只在浏览器内存，不上传、不写localStorage。建议事先移除个人信息。多问题评价按首个关键词命中分类，未命中待人工确认；页面仅显示前100行，导出保留全部数据供进一步核对。
